# 03 注册外区 Apple ID——给 iPhone 装上"海外商店通行证"

> 适合谁：路线 A（iPhone 用户）。
> 本章目标：注册一个**美区 Apple ID**，用来下载小火箭（VPN 工具）、ChatGPT 等国内商店没有的 App。

## 3.1 为什么必须注册外区 ID

两个硬原因 [Y1正文]：

1. **国区 App Store 没有小火箭（Shadowrocket）**——它是 iOS 主流代理客户端，只在美区上架；
2. **国区 App Store 没有 ChatGPT 官方 App**，以及很多海外未引进的 App。

> 一句话：**国区商店 = 你后面所有路都堵死。外区 ID = 开门钥匙。**

## 3.2 注册前的准备

- [ ] 一个**没注册过 Apple ID 的邮箱**（建议用 [章节02](/p/chatgpt-subscription-02-google-account/) 刚注册的 Gmail，顺手且一致）[U]；
- [ ] 一个**能收验证码的手机号**——**可以是国内的 +86 号码** [Y1正文]；
- [ ] 网络：**按 [Y1正文] 的说法，注册全程不需要梯子**（⚠️ 待核验：少数资料称 Apple 会根据 IP 判断地区，若遇异常，可开启美国节点重试）。

## 3.3 注册步骤（约 5 分钟）

> 用电脑浏览器或手机浏览器打开网页注册，比在 iPhone 设置里注册更稳。

1. 打开 **http://appleid.apple.com**；
2. 点 **"创建你的 Apple 账户" / Create Your Apple Account**；
3. 填信息：
   - **名字**：随便填（英文）；
   - **地区/国家**：**选美国** ← 关键；
   - **生日**：**填 18 岁以上**（随便填一个成年日期）[Y1正文]；
   - **邮箱**：填你的 Gmail；
   - **手机号**：**直接填自己的国内 +86 号码** [Y1正文]；
4. 邮箱和手机号都会收到验证码，按提示输入；
5. 设置登录密码（字母+数字组合）和安全提示问题；
6. 创建成功。

### 验证是否成功

打开 **App Store → 退出当前账号 → 登录这个新美区 ID → 搜索 "Shadowrocket"**：

- **能搜到** = 美区 ID 注册成功（最直接的验收方法）[Y1正文]；
- 搜不到 = 地区可能没切对，检查账号地区是否为美国。

## 3.4 两个关键设置（容易踩坑）

### ① 付款方式选"无 / None"

注册阶段**不要绑任何银行卡**，付款方式选"无" [G]。后面怎么付钱：

- 想买小火箭 → [章节05 →](/p/chatgpt-subscription-05-gift-card/)（礼品卡，无卡可用）；
- 想绑招行卡 → [章节11 →](/p/chatgpt-subscription-11-bank-card/)。

### ② 账单地址填美国（免税州更佳）

在 Apple ID 设置里，把**账单地址（Billing Address）填成美国地址**，帖子里建议用**免税州**（如 Oregon 俄勒冈、Alaska 阿拉斯加、Delaware 特拉华等）的地址 [Y1评论]。

> ⚠️ **待核验硬点**：免税州清单、以及 Apple 内购是否真的按账单地址免税，需要核实后再写进最终版（见下方待核验点）。

## 3.5 账号隔离：外区小号只用于 App Store

**强烈建议**：这个外区 ID 只用来登录 **App Store（媒体与购买项目）**，**iCloud 继续用你的国区主账号** [G]。

| 用途 | 用哪个账号 |
|---|---|
| iCloud（照片/通讯录/备忘录/备份） | 国区主 Apple ID |
| App Store 下载 App / 购买 | 外区美区 Apple ID |

这样避免：照片同步乱套、备忘录混到外国服务器、以及外区账号一旦出问题连累你的个人数据 [G]。

## 3.6 三个"绝对不要"

- ❌ **不要买别人"现成"的外区 ID**：可能是黑卡注册、批量注册，随时被封，连累你的设备/数据 [G]；
- ❌ **不要把自己的国区主账号直接改地区**：改区有各种限制和风险，注册小号更干净 [G]；
- ❌ **不要把密码告诉"代注册/代充"服务**：账号被找回你什么都没了 [G]。

## 3.7 保存好账号信息

注册完成后，把以下信息记到密码管理器或加密笔记（**别存明文聊天记录**）：

- 邮箱、密码、安全提示问题答案、恢复信息；
- 备注：这个 ID 的用途（仅 App Store）。

## 本章常见问题

**Q：注册外区 ID 一定要梯子吗？**
A：按 [Y1正文] 不需要；若你注册时遇到地区限制异常，可连美国节点重试（待核验）。

**Q：+86 手机号真的能注册美区 ID？**
A：[Y1正文] 明确说可以，帖主亲测；这也是本章把它当主流程的原因。若你的 +86 收不到验证码，检查短信拦截、稍后重试。

**Q：外区 ID 会和我的 iCloud 冲突吗？**
A：不会，前提是**只在外区 ID 登录 App Store，iCloud 保持国区主号**（3.5 节）[G]。

**Q：为什么我 App Store 搜不到 ChatGPT？**
A：确认已用**美区 ID** 登录 App Store（点头像看账号地区）；ChatGPT 在美区商店是"ChatGPT"官方 App，开发商 OpenAI [G]。
