## 适用范围

本政策适用于 **碳基漫游 AI** 公开站点 [xizhiyun1995-netizen.github.io](https://xizhiyun1995-netizen.github.io/) 的页面，以及 `/admin/` CMS 管理入口。

本站是通过 GitHub Pages 发布的静态 Hugo 网站。以下内容是对当前配置的实际说明，并不承诺未来接入服务后仍完全相同。如果以后启用统计、评论、表单、订阅、广告、支付或其他第三方服务，应先更新本政策。

## 公开页面目前不收集什么

当前公开站点没有访客账户、评论、联系表单、邮件订阅、广告、支付功能，也没有自有用户数据库。普通访问页面不会主动向站点所有者收集或保存姓名、邮箱、IP 地址、上传文件或留言内容。

评论功能已关闭。当前没有启用 Google Analytics、Microsoft Clarity、广告像素或其他站点配置的统计标识。站点也不会为访客设置第一方 Cookie。

作为托管服务商，GitHub Pages 可能依据 GitHub 自身的政策处理 IP 地址、User-Agent、访问时间等技术请求信息。站点所有者不运营这部分基础设施，也不会通过本站取得一份由站点自己维护的访问日志。

## 浏览器本地存储

主题会在访客浏览器中保存两项界面偏好：

- `StackColorScheme`：浅色、深色或跟随系统的配色选择；
- `liquid-stack-language-preference`：英文或简体中文语言选择。

这些值保存在浏览器的 `localStorage` 中，不写入站点数据库，也不会提交给站点所有者。清除浏览器本地存储后，相关偏好会恢复默认值。

## 外部链接与资源

文章和导航可能链接到 GitHub、X、官方文档、模型服务商或其他外部网站。打开外部链接后，相关交互由对应服务自己的隐私政策、服务条款、Cookie 和日志规则约束，站点所有者无法控制这些服务。

公开页面不会加载 CMS 编辑器。访问 `/admin/` 时，页面会从 `unpkg.com` 加载 Sveltia CMS JavaScript；该管理界面可能与 GitHub 通信以完成身份验证和仓库编辑。使用前请阅读下一节。

## CMS 与 GitHub 仓库

CMS 是管理工具，不是面向公众的投稿表单。使用者必须拥有该 GitHub 仓库的写入权限。授权后的编辑会直接提交到公开仓库的 `main` 分支，并可能触发 GitHub Actions 与 GitHub Pages 部署流程。

不要把密码、API Key、验证码、恢复代码、私钥、Cookie 或真实用户数据填写到文章正文或 CMS 字段中。提交到公开仓库的内容可能被任何人访问。GitHub 账户认证和账户信息处理遵循 GitHub 自身的政策；站点所有者不会收到你的 GitHub 密码。

## 数据保留与安全

站点所有者不建立访客画像，也不维护自有的评论或统计数据库。提交到仓库的公开文章、配置和媒体文件会保留在 Git 历史中，除非通过正常的 Git 和托管流程删除。任何在线系统都无法保证绝对安全，请不要通过公开页面或 CMS 提交机密信息。

## 政策变更

当站点的托管、脚本、统计、评论、CMS 或其他数据处理方式发生变化时，本政策可能更新。页面顶部的日期表示最近一次修订时间。
